- Aksi yang digunakan: Lihat, Tambah, Ubah, Hapus, dan Setujui jika modul mendukung approval.
- Role yang tidak dipakai user tetap ada di database, tetapi tidak dirinci di bagian detail agar laporan fokus pada akses user aktif.
